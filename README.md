# Car Stile — сайт с онлайн-записью

Статический лендинг для мастерской автоухода **Car Stile** (Павлодар, ул. Желтоксан, 85).
Собирается и запускается без сборщиков и без сервера.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: hero → быстрый выбор задачи → услуги → до/после → варианты химчистки → цены → отзывы → форма записи → FAQ → контакты с картой |
| `styles.css` | Дизайн-система: токены, компоненты, адаптив, reduced-motion |
| `app.js` | Форма записи (3 шага), валидация, слайдер «до/после», галерея-лайтбокс, аккордеон FAQ, мобильное меню |
| `assets/` | 13 фотографий работ |

## Как запустить

Просто открыть `index.html` в браузере. Для публикации подойдёт любой статический хостинг
(обычный хостинг по FTP, GitHub Pages, Netlify, Vercel, Cloudflare Pages) — достаточно загрузить
всю папку целиком.

Локально с сервером (удобно для проверки на телефоне в той же сети):

```bash
python -m http.server 8080
```

## Как работает запись

Отдельного сервера нет. Форма из трёх шагов собирает заявку и **открывает WhatsApp мастерской
с уже готовым текстом сообщения**; ниже показывается тот же текст с кнопкой «Скопировать» — на
случай, если окно WhatsApp не открылось. Всё, что нужно сделать клиенту, — нажать «Отправить»
в WhatsApp.

Что валидируется: услуга, марка/модель, дата (не раньше сегодняшнего дня), время, имя, телефон
(минимум 10 цифр) и согласие на обработку данных. Ошибки показываются и рядом с полем, и
сводным блоком сверху формы — с переходом к проблемному полю.

Если в будущем понадобится реальная онлайн-запись с расписанием слотов и подтверждением,
потребуется бэкенд или CRM — тогда форму можно переключить с WhatsApp на API.

## Технические решения

- **Дизайн-система.** Направление построено скиллом `ui-ux-pro-max`: премиальная палитра
  «чёрный + золото» (`#0c0a09` / `#c9a227`), шрифты Montserrat (заголовки) + Inter (текст).
- **Компоненты.** Токены и API повторяют конвенции shadcn/ui (`--background`, `--foreground`,
  `--card`, `--border`, `--ring`, compound-структура `card__head/body/foot`, варианты кнопок,
  паттерн Field + Label + Input), доступность — по принципам Astryx (видимый фокус, семантические
  роли, `aria-live` для ошибок и статуса отправки). Сами библиотеки — React/StyleX-решения со
  сборкой; здесь те же приёмы реализованы на чистом HTML/CSS/JS, чтобы сайт оставался одним
  лёгким каталогом, который открывается локально и публикуется где угодно без CI.
  Если нужна кодовая база на React + shadcn/Astryx — это отдельный шаг.
- **Доступность.** Скип-ссылка, все инпуты с `<label for>`, ошибки через `role="alert"` и
  `aria-invalid`, сводка ошибок с фокусом, зоны нажатия 44 px, контраст ≥ 4.5:1, поддержка
  `prefers-reduced-motion` (бегущая строка и анимации появления отключаются).
- **Адаптив.** Контрольные ширины 375 / 768 / 1024 / 1440. Горизонтального скролла нет,
  телефоны и WhatsApp — через `tel:` и `wa.me`.
- **Вес.** ~4,8 МБ вместе с фотографиями, все изображения сжаты и грузятся лениво ниже первого экрана.

## Что стоит уточнить у владельца до публикации

1. **Обрезанные цены.** В каталоге сумм не хватает: детейлинг-мойка («от 12.000…») и химчистка
   без разбора («от 45…»). Пришлите точные значения — поставим их на сайт.
2. **Актуальность цен** 50 000 / 15 000 / 4 000 ₸ и сезонных 6 000 ₸ за консервацию шин.
3. **Антикоррозийное покрытие днища и озонирование** — состав и чем озонация отличается от сухого тумана.
4. **Название бренда.** На площадках встречаются Car Stile, CAR STAIL и «kolumb» (в WhatsApp-каталоге).
   Нужно выбрать официальное написание — сейчас на сайте используется «Car Stile».
5. **Логотип и фирменные цвета.** Настоящего исходника логотипа нет: сейчас стоит текстовая
   марка, собранная заново. Пришлите SVG/PNG — поставим настоящий знак.
6. **Фотографии.** Стоят фото из 2GIS. Лучше заменить на собственные исходники (без плашки) и
   добавить: фото входа/фасада, бокс, команду, пары «до/после» в одном ракурсе.
   *Фото фасада из карточки 2GIS не использованы: на них крупно видны вывески других организаций,
   и как «наш вход» они бы запутали клиента.*
7. **Время работ и правила.** Средняя длительность по каждой услуге, приём/выдача, нужна ли
   ночёвка автомобиля, сроки сушки после химчистки.
8. **Юридические данные.** Наименование/БИН и текст политики обработки персональных данных —
   сейчас на форме только галочка согласия без ссылки на политику.
9. **Состав услуг.** Что именно входит в каждый вариант химчистки (без разбора / частичный / полный)
   и в шумоизоляцию — чтобы заменить осторожные формулировки на конкретику.

## Что в формулировках намеренно не заявлено

Гарантия, «лучшие мастера», «сертифицировано», «премиальное оборудование», стаж, бренды
материалов, число клиентов и абсолютное устранение любых царапин/запаха — всё это на сайте
не используется, потому что публичными источниками не подтверждается. Если владелец предоставит
документы, формулировки можно усилить.
